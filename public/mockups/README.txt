APPAREL MOCKUP ASSET PACK

76 transparent PNG mockups for ecommerce product customization.
Canvas: 1600 x 2000 pixels
Background: transparent alpha
Products: tee, hoodie, polo
Views: front, back, left-sleeve, right-sleeve
Naming: {view}-{color}.png

The masters directory contains the locked neutral-gray source view for each
product/view. All color variants share the exact same canvas, silhouette,
placement, lighting, folds, and alpha boundary within their product/view.

These are screen-preview assets. Production artwork should be exported
separately to the printer's required dimensions, color profile, and 300 DPI.
